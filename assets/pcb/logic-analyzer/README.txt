Logic Analyzer Board — Media Assets
=====================================
Drop your files here. The gallery loads them automatically —
missing files are silently skipped.

  schematic.jpg   — Full schematic capture (from Altium Designer)
  board.jpg       — Board layout / 3D render or photo of bare PCB
  detail_01.jpg   — Optional detail shot #1
  detail_02.jpg   — Optional detail shot #2

Supported formats: JPG or PNG
Recommended image width: 1200px+ for best quality
Clicking any image opens it full-size in a new tab.

To add more boards to the gallery, edit the boards[] array
in rey_soto_portfolio.html (search for "PCB board gallery").
