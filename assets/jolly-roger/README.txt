Jolly Roger -- Media Assets
===========================
Drop your files into this folder. Everything loads automatically --
files that are missing are silently skipped, so add what you have.

VIDEOS  (2 slots)
-----------------
  jolly_roger_video_01.mp4   -- labelled "Full Demo"
  jolly_roger_video_02.mp4   -- labelled "Mechanism Detail"

  To rename the labels, edit the label: values in the script
  block inside rey_soto_portfolio.html (search for jrVideos).
